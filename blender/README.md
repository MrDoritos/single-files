# Blender

- MMB, mouse move - 3D orbit
- Scroll up, down - zoom
- Ctrl MMB, mouse move fwd, bwd - adjust zoom multiplier
- Shift MMB, mouse move - pan

- Shift-A - add
- x - remove
- a - select all / none
- Ctrl-D - dup
- Alt-D - link
- Ctrl-P - parent
- m - move collection
- space - search
- Shift-Space - pause/resume
- n - properties
- t - toolbar
- f12 - render 
- f11 - view render 
- Ctrl-S save
- Ctrl-Alt-S save as
- Ctrl-Page-Up workspace next
- Ctrl-Page-Down workspace down
